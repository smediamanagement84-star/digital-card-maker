## Troubleshooting

### Can't Create Multiple Cards with One Account?
**Solution:**
- Option 1: Use different Google accounts
- Option 2: Create, screenshot, delete, create new
- Option 3: Check if app supports multiple cards per user

### Photo Upload Not Working?
**Solution:**
- Check file size (< 5MB recommended)
- Use JPG or PNG format
- Verify internet connection
- Check browser console for errors

### Custom URL Already Taken?
**Solution:**
- Try variations (rajesh-kumar → rajeshkumar → rajesh-ku)
- Add numbers (rajesh-kumar-1)
- Use alternative format

### QR Code Not Generating?
**Solution:**
- Refresh the page
- Check browser console
- Verify card is saved
- Try different browser
